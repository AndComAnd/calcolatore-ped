# Calcolatore PED 2014/68/UE

Apri l'app: https://andcomand.github.io/calcolatore-ped/

Su smartphone: Android (Chrome) menu > "Installa app"; iPhone (Safari) Condividi > "Aggiungi alla schermata Home".
